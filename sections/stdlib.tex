\section{C standard library}

\begin{frame}{C standard library}
	\begin{itemize}
		\item A complete ANSI C compatible standard library has been implemented by Tobias Oehme (master thesis)
		\item This allows existing software to be ported to hhuOS
		\item Ported applications:
		\begin{itemize}
			\item Doom via doomgeneric
			\item Quake via quakegeneric
			\item Peanut-GB (GameBoy emulator)
			\item ClownMDEmu (Mega Drive emulator)
			\item ClassiCube (Minecraft Classic reimplementation)
		\end{itemize}
	\item Ported libraries:
	\begin{itemize}
		\item TinyGL (OpenGL 1 software rendering)
		\item PortableGL (OpenGL 3 software rendering)
	\end{itemize}
  \end{itemize}
\end{frame}
